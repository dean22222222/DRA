# EJSHS Thespian Troupe 58 & Drama Club — Admin Edition

Open `index.html` for the public site.

Open `admin.html` for the editor.

## Admin
Default password: `theater58`

The dashboard can edit:
- School/hero text
- About section
- Performing / Tech / Community cards
- Show title and description
- Join section
- Contact email
- Upcoming events (add/remove/edit)
- Admin password

### Important
This version uses browser `localStorage` and `sessionStorage`, so changes are stored in the browser being used. The password is not secure server-side authentication. For a real school/public website, connect the dashboard to a backend/database with proper authentication.
